A reading guide

To read the code from top to bottom, I recommend this order, which follows a single item through the kiosk: kiosk_app.py (start-up and tick), then hx711.py and weight_filter.py (how the weight becomes steady), then camera.py and cnn_numpy.py (how the item gets its name), then bill.py (how the name and weight become money). The training files come last; the kiosk never runs them.

Most choices in the code are explained in the chapter about that part. Here are the ones that are easy to miss when reading the code alone.

Why does every file find its files relative to itself?

Each file starts with HERE = Path(__file__).resolve().parent and builds every path from it. The kiosk is started by systemd, the tests from a terminal in any folder, and training on a laptop with a different home folder. Paths built from the file's own location work in all of these. Version 1's paths such as C:/Users/.../Downloads/best.pt worked on exactly one laptop.

Why is the crops file stored as whole numbers?

prepare_dataset.py stores crops as uint8 (0 to 255) and train.py divides by 255 when it uses them. The prepared values are exactly whole numbers divided by 255, so nothing is lost, and the file is four times smaller than float32: about 23 MB instead of 91 MB for 1,850 crops.

Why does train.py --synthetic write into its own folder?

The synthetic run proves the code learns, but its weights know shapes, not fruit. Writing them to classifier/synthetic_run/ means they can never overwrite the real weights.npz or be copied to the Pi by mistake.

Why does augment pad with "edge"?

Shifting a crop by up to 4 pixels leaves an empty strip on one side. Filling it with zeros would add a black border that never appears at the kiosk. np.pad(..., mode="edge") repeats the outermost pixels instead, which on a crop is the blue tray, so a shifted crop still looks like a real one.

Why does train.py measure the 0.60 rule on the test pile?

It only counts how many test crops fall above and below 0.60 and how many of each were right, so I can report what the rule does. The threshold itself was chosen on the validation pile, never on the test pile, so this count does not leak into any decision.

Be careful

hx711.py, camera.py and calibrate.py touch hardware. Without RPi.GPIO the HX711 class still imports and runs, but its stand-in GPIO always reads 0, so read_raw returns 0. That is useful for checking that the code imports and runs, and useless as a scale. For laptop demos the code uses SimulatedHX711 and FakeCamera instead.

# Edge-AI Self-Checkout Kiosk (version 2)

A self-checkout kiosk for loose fruit and vegetables. A customer puts one item on the tray;
the kiosk weighs it with a load cell, recognises it with a small CNN written from scratch in
NumPy, and adds a line to an itemised bill on a touchscreen. Everything runs on one
Raspberry Pi 4. No PyTorch, no TensorFlow, no cloud.

- 12 classes: Apple, Beetroot, Brinjal, Brinjal White, Coconut, Guava, Lemon, Mosambi,
  Onion, Pomegranate, Potato, Tomato
- CNN: 3 conv layers (8, 16, 32 filters of 3 x 3) + 2 dense layers, 80,604 weights,
  64 x 64 RGB input, every forward and backward pass hand-written in NumPy
- Scale: 5 kg bar load cell + HX711, read directly on GPIO 5 (DT) and GPIO 6 (SCK),
  median-of-5 filter, "steady" when 8 readings agree within 2 g
- App: Tkinter, fullscreen 800 x 480, money kept in whole paise

classifier/cnn_numpy.py

The network and the image preparation. Used by training on the laptop and by the kiosk on the Pi. 313 lines.

"""cnn_numpy.py - the whole image classifier of the kiosk, written with NumPy only.

This one file is used in two places:
  * on the laptop, train.py imports it to TRAIN the network,
  * on the Raspberry Pi, kiosk_app.py imports it to PREDICT one photo.
Because both sides import the same file, the layers can never drift apart.

Shapes used everywhere:
  a batch of pictures  x : (N, C, H, W) = (how many, channels, rows, columns)
  a batch of scores      : (N, 12)

Every layer has two methods:
  forward(x)   takes the input, remembers what it needs, returns the output
  backward(d)  takes "how much the loss changes with my output" (d) and returns
               "how much the loss changes with my input"; on the way it stores
               the gradients of its own weights in self.dW and self.db
"""
import numpy as np

# The 12 classes in their fixed order. Index 0 is Apple, index 11 is Tomato.
# This order is baked into the trained weights, so it must never change.
CLASSES = ["Apple", "Beetroot", "Brinjal", "Brinjal White", "Coconut", "Guava",
           "Lemon", "Mosambi", "Onion", "Pomegranate", "Potato", "Tomato"]

IMAGE_SIZE = 64      # the network sees 64 x 64 pictures
CROP_MARGIN = 0.10   # every item box is grown by 10% on each side before cropping


# ----------------------------------------------------------------------------
# Image preparation (the only part that uses OpenCV)
# ----------------------------------------------------------------------------
def crop_with_margin(bgr, box, margin=CROP_MARGIN):
    """Cut the box (x, y, w, h) out of a photo, grown by a margin on each side."""
    x, y, w, h = box
    mx, my = int(round(w * margin)), int(round(h * margin))
    rows, cols = bgr.shape[:2]
    x0, y0 = max(0, x - mx), max(0, y - my)
    x1, y1 = min(cols, x + w + mx), min(rows, y + h + my)
    return bgr[y0:y1, x0:x1]


def prepare_image(bgr):
    """Turn one BGR crop of any size into the block the network eats.

    Steps: pad to a square with the border colour -> BGR to RGB ->
    resize to 64 x 64 -> float32 in 0..1 -> shape (1, 3, 64, 64).
    The SAME function is used for training crops and for kiosk photos.
    """
    import cv2  # imported here so the maths below also works without OpenCV
    h, w = bgr.shape[:2]
    # The colour of the crop's outer frame of pixels (the tray), one value per channel.
    border = np.concatenate([bgr[0], bgr[-1], bgr[:, 0], bgr[:, -1]])
    colour = [int(v) for v in np.median(border, axis=0)]
    # Pad the short side equally on both ends so the item keeps its true shape.
    side = max(h, w)
    top, left = (side - h) // 2, (side - w) // 2
    square = cv2.copyMakeBorder(bgr, top, side - h - top, left, side - w - left,
                                cv2.BORDER_CONSTANT, value=colour)
    rgb = cv2.cvtColor(square, cv2.COLOR_BGR2RGB)
    small = cv2.resize(rgb, (IMAGE_SIZE, IMAGE_SIZE), interpolation=cv2.INTER_AREA)
    x = small.astype(np.float32) / 255.0          # 0..255 -> 0..1
    x = x.transpose(2, 0, 1)                      # (64, 64, 3) -> (3, 64, 64)
    return x[None]                                # add the batch axis -> (1, 3, 64, 64)


# ----------------------------------------------------------------------------
# A slow convolution, only for understanding and for testing the fast one
# ----------------------------------------------------------------------------
def conv_forward_slow(x, W, b):
    """Convolution of ONE picture x (C, H, W) with plain Python loops.

    W is (F, C, k, k): F filters, each C channels deep and k x k wide.
    This is the textbook definition. It is far too slow to train with.
    """
    F, C, k, _ = W.shape
    H_out, W_out = x.shape[1] - k + 1, x.shape[2] - k + 1
    out = np.zeros((F, H_out, W_out), x.dtype)
    for f in range(F):                      # every filter
        for r in range(H_out):              # every output row
            for c in range(W_out):          # every output column
                patch = x[:, r:r + k, c:c + k]            # the k x k window, all channels
                out[f, r, c] = np.sum(patch * W[f]) + b[f]
    return out


# ----------------------------------------------------------------------------
# The layers
# ----------------------------------------------------------------------------
class Conv:
    """Convolution layer, k x k filters, no padding, stride 1."""

    def __init__(self, c_in, c_out, k=3, rng=None, dtype=np.float32, need_dx=True):
        rng = rng or np.random.default_rng(0)
        fan_in = c_in * k * k                               # inputs feeding one output number
        # He initialisation: random numbers with spread sqrt(2 / fan_in).
        self.W = (rng.standard_normal((c_out, c_in, k, k)) * np.sqrt(2.0 / fan_in)).astype(dtype)
        self.b = np.zeros(c_out, dtype)
        self.k = k
        self.need_dx = need_dx      # the first layer has nobody to pass blame to

    def forward(self, x):
        self.x = x                                          # remember the input for backward
        N, C, H, W = x.shape
        k = self.k
        Ho, Wo = H - k + 1, W - k + 1
        out = np.zeros((N, self.W.shape[0], Ho, Wo), x.dtype)
        # Loop over the 9 cells of the filter, NOT over the pixels.
        # For cell (i, j): take the input shifted by (i, j) and multiply it by
        # that cell's weights for all pictures, channels and positions at once.
        for i in range(k):
            for j in range(k):
                shifted = x[:, :, i:i + Ho, j:j + Wo]       # (N, C, Ho, Wo)
                out += np.einsum("nchw,fc->nfhw", shifted, self.W[:, :, i, j], optimize=True)
        out += self.b[None, :, None, None]
        return out

    def backward(self, d):
        x, k = self.x, self.k
        Ho, Wo = d.shape[2], d.shape[3]
        self.dW = np.zeros_like(self.W)
        self.db = d.sum(axis=(0, 2, 3))                     # each bias touched every output of its map
        dx = np.zeros_like(x) if self.need_dx else None
        for i in range(k):
            for j in range(k):
                shifted = x[:, :, i:i + Ho, j:j + Wo]
                # Blame for weight (f, c, i, j) = sum of (blame of output) x (input it multiplied).
                self.dW[:, :, i, j] = np.einsum("nfhw,nchw->fc", d, shifted, optimize=True)
                if self.need_dx:
                    # Blame for the input = blame of every output it fed, times the weight used.
                    dx[:, :, i:i + Ho, j:j + Wo] += np.einsum(
                        "nfhw,fc->nchw", d, self.W[:, :, i, j], optimize=True)
        return dx


class ReLU:
    """Keep positive numbers, turn negative numbers into 0."""

    def forward(self, x):
        self.keep = x > 0
        return x * self.keep

    def backward(self, d):
        return d * self.keep            # blame passes only where the input was positive


class MaxPool:
    """2 x 2 max pooling: keep the biggest of every 2 x 2 block."""

    def forward(self, x):
        N, C, H, W = x.shape
        Ho, Wo = H // 2, W // 2                              # an odd last row/column is dropped
        self.in_shape = x.shape
        blocks = x[:, :, :2 * Ho, :2 * Wo].reshape(N, C, Ho, 2, Wo, 2)
        blocks = blocks.transpose(0, 1, 2, 4, 3, 5).reshape(N, C, Ho, Wo, 4)   # 4 numbers per block
        winner = blocks.argmax(axis=4)                       # which of the 4 was biggest
        self.mask = np.arange(4) == winner[..., None]        # True at the winner only
        return blocks.max(axis=4)

    def backward(self, d):
        N, C, H, W = self.in_shape
        Ho, Wo = H // 2, W // 2
        blocks = self.mask * d[..., None]                    # all blame to the winner, 0 to the rest
        blocks = blocks.reshape(N, C, Ho, Wo, 2, 2).transpose(0, 1, 2, 4, 3, 5)
        dx = np.zeros(self.in_shape, d.dtype)
        dx[:, :, :2 * Ho, :2 * Wo] = blocks.reshape(N, C, 2 * Ho, 2 * Wo)
        return dx


class Flatten:
    """Unroll (N, C, H, W) into (N, C*H*W). No maths, only a new shape."""

    def forward(self, x):
        self.in_shape = x.shape
        return x.reshape(x.shape[0], -1)

    def backward(self, d):
        return d.reshape(self.in_shape)


class Dense:
    """Fully connected layer: every input is joined to every output."""

    def __init__(self, n_in, n_out, rng=None, dtype=np.float32):
        rng = rng or np.random.default_rng(0)
        self.W = (rng.standard_normal((n_in, n_out)) * np.sqrt(2.0 / n_in)).astype(dtype)
        self.b = np.zeros(n_out, dtype)

    def forward(self, x):
        self.x = x
        return x @ self.W + self.b

    def backward(self, d):
        self.dW = self.x.T @ d          # (n_in, n_out)
        self.db = d.sum(axis=0)
        return d @ self.W.T             # blame for the inputs


# ----------------------------------------------------------------------------
# Softmax and the loss
# ----------------------------------------------------------------------------
def softmax(z):
    """Turn each row of scores into chances that are positive and add up to 1."""
    z = z - z.max(axis=1, keepdims=True)        # does not change the answer, avoids huge exp()
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)


def loss_and_grad(scores, y):
    """Cross-entropy loss of a batch, and its gradient with respect to the scores.

    scores : (N, 12) raw outputs of the last layer
    y      : (N,) the right class index of each picture
    Returns (loss, d) where d has the shape of scores and feeds Net.backward.
    """
    N = scores.shape[0]
    p = softmax(scores)
    loss = -np.mean(np.log(p[np.arange(N), y] + 1e-12))
    d = p.copy()
    d[np.arange(N), y] -= 1.0                   # chances minus the one-hot answer
    return float(loss), d / N


# ----------------------------------------------------------------------------
# The network
# ----------------------------------------------------------------------------
class Net:
    """3 x 64 x 64 -> conv 8 -> pool -> conv 16 -> pool -> conv 32 -> pool -> 64 -> 12."""

    def __init__(self, seed=0, dtype=np.float32):
        rng = np.random.default_rng(seed)
        self.layers = [
            Conv(3, 8, rng=rng, dtype=dtype, need_dx=False), ReLU(), MaxPool(),   # -> 8 x 31 x 31
            Conv(8, 16, rng=rng, dtype=dtype), ReLU(), MaxPool(),                 # -> 16 x 14 x 14
            Conv(16, 32, rng=rng, dtype=dtype), ReLU(), MaxPool(),                # -> 32 x 6 x 6
            Flatten(),                                                            # -> 1,152
            Dense(32 * 6 * 6, 64, rng=rng, dtype=dtype), ReLU(),                  # -> 64
            Dense(64, len(CLASSES), rng=rng, dtype=dtype),                        # -> 12 scores
        ]
        # The layers that own weights, with the names used in weights.npz.
        idx = [0, 3, 6, 10, 12]
        names = ["conv1", "conv2", "conv3", "dense1", "dense2"]
        self.named = [(n, self.layers[i]) for n, i in zip(names, idx)]
        # One "velocity" array per weight array, for momentum.
        self.velocity = {(n, p): np.zeros_like(getattr(layer, p))
                         for n, layer in self.named for p in ("W", "b")}

    def forward(self, x):
        for layer in self.layers:
            x = layer.forward(x)
        return x                                 # (N, 12) scores, softmax NOT applied yet

    def backward(self, d):
        for layer in reversed(self.layers):
            d = layer.backward(d)

    def step(self, lr=0.01, momentum=0.9):
        """One SGD-with-momentum update of every weight, using the stored gradients."""
        for name, layer in self.named:
            for p in ("W", "b"):
                w = getattr(layer, p)                        # the weight array itself
                v = self.velocity[(name, p)]                 # its velocity array
                v *= momentum                                # keep 90% of the old direction
                v -= lr * getattr(layer, "d" + p)            # add a step downhill
                w += v                                       # move the weights, in place

    def count_weights(self):
        return sum(layer.W.size + layer.b.size for _, layer in self.named)

    def get_weights(self):
        """A dictionary of copies of the 10 weight arrays."""
        return {f"{n}_{p}": getattr(layer, p).copy() for n, layer in self.named for p in ("W", "b")}

    def set_weights(self, arrays):
        for n, layer in self.named:
            for p in ("W", "b"):
                a = arrays[f"{n}_{p}"]
                if a.shape != getattr(layer, p).shape:
                    raise ValueError(f"{n}_{p}: file has {a.shape}, network needs {getattr(layer, p).shape}")
                setattr(layer, p, a.astype(getattr(layer, p).dtype))

    def save_weights(self, path):
        np.savez(path, **self.get_weights())

    def load_weights(self, path):
        with np.load(path) as data:
            self.set_weights({k: data[k] for k in data.files})


def predict(net, x):
    """Class index and confidence (0..1) for ONE prepared picture x of shape (1, 3, 64, 64)."""
    p = softmax(net.forward(x))[0]
    best = int(p.argmax())
    return best, float(p[best])


def top_k(net, x, k=3):
    """The k most likely classes for one picture, best first: [(class_index, chance), ...]."""
    p = softmax(net.forward(x))[0]
    order = np.argsort(p)[::-1][:k]
    return [(int(i), float(p[i])) for i in order]


if __name__ == "__main__":
    # A tiny self-test: the fast convolution must agree with the slow textbook one.

"""prepare_dataset.py - turn the version 1 photos and YOLO boxes into 64 x 64 crops.

Input (from version 1):
  dataset/images/<photo>.jpg     top-view photos of the tray
  dataset/labels/<photo>.txt     one line per box: class cx cy w h (fractions of the photo size)
Output:
  classifier/data/dataset_64.npz  x_train, y_train, x_val, y_val, x_test, y_test (uint8 crops, int labels)
  classifier/data/split.csv       which photo went to which pile

Steps:
  1. Read every label file. Map the 14 version 1 class numbers to my 12 classes BY NAME.
     Capsicum and Chilly are dropped (15 and 17 photos: too few to learn or to test).
  2. Split the PHOTOS (not the crops) into train / validation / test, 70 / 15 / 15
     within each class, with a fixed seed, so near-identical crops of one photo
     can never be on both sides of the split.
  3. Cut every box out with a 10% margin and prepare it with the SAME function the
     kiosk uses (pad to square, RGB, 64 x 64). Store as whole numbers 0..255.

Run:  python prepare_dataset.py --images ../dataset/images --labels ../dataset/labels
"""
import argparse
import csv
from collections import Counter
from pathlib import Path

import cv2
import numpy as np

from cnn_numpy import CLASSES, crop_with_margin, prepare_image

def make_synthetic(per_class=(60, 15, 15), seed=0):
    """12 classes of coloured shapes on a blue tray, prepared exactly like real crops.

    Each class is a (shape, colour) pair; size, position, colour shade and
    brightness vary randomly, so the network has to learn shape AND colour.
    """
    import cv2
    rng = np.random.default_rng(seed)
    shapes = ["circle", "square", "triangle", "ellipse"]
    colours = [(40, 40, 200), (60, 200, 230), (60, 170, 60)]          # BGR: red, yellow, green
    kinds = [(s, c) for s in shapes for c in colours]                  # 4 x 3 = 12 classes
    piles = []
    for n in per_class:
        xs, ys = [], []
        for k, (shape, colour) in enumerate(kinds):
            for _ in range(n):
                h, w = rng.integers(90, 140), rng.integers(90, 140)
                img = np.zeros((h, w, 3), np.uint8)
                img[:] = (200, 120, 40)                                 # tray blue
                c = [int(np.clip(v + rng.integers(-30, 31), 0, 255)) for v in colour]
                cx, cy = w // 2 + rng.integers(-8, 9), h // 2 + rng.integers(-8, 9)
                r = int(min(h, w) * rng.uniform(0.25, 0.38))
                if shape == "circle":
                    cv2.circle(img, (int(cx), int(cy)), r, c, -1)
                elif shape == "square":
                    cv2.rectangle(img, (int(cx - r), int(cy - r)), (int(cx + r), int(cy + r)), c, -1)
                elif shape == "triangle":
                    pts = np.array([[cx, cy - r], [cx - r, cy + r], [cx + r, cy + r]], np.int32)
                    cv2.fillPoly(img, [pts], c)
                else:
                    cv2.ellipse(img, (int(cx), int(cy)), (r, r // 2), int(rng.integers(0, 180)), 0, 360, c, -1)
                img = np.clip(img * rng.uniform(0.85, 1.15), 0, 255).astype(np.uint8)
                xs.append(np.round(prepare_image(img)[0] * 255).astype(np.uint8))
                ys.append(k)
        piles.append((np.stack(xs), np.array(ys, np.int64)))
    names = [f"{s} {['red', 'yellow', 'green'][i % 3]}" for s in shapes for i in range(3)]
    return piles, names


def to_float(x_uint8):
    return x_uint8.astype(np.float32) / 255.0


def augment(x, rng):
    """Random flip, shift up to 4 pixels and brightness 0.85..1.15, for TRAINING batches only."""
    x = x.copy()
    n = len(x)
    flip = rng.random(n) < 0.5
    x[flip] = x[flip][..., ::-1]                                       # mirror left-right
    padded = np.pad(x, ((0, 0), (0, 0), (4, 4), (4, 4)), mode="edge")  # repeat the border pixels
    dy, dx = rng.integers(0, 9, n), rng.integers(0, 9, n)              # shift of -4..+4
    for i in range(n):
        x[i] = padded[i, :, dy[i]:dy[i] + 64, dx[i]:dx[i] + 64]
    x *= rng.uniform(0.85, 1.15, (n, 1, 1, 1)).astype(np.float32)
    return np.clip(x, 0.0, 1.0)

def evaluate(net, x_uint8, y, batch=128):
    """Accuracy, average loss and the predicted class of every picture."""
    preds, losses = [], []
    for i in range(0, len(y), batch):
        scores = net.forward(to_float(x_uint8[i:i + batch]))
        loss, _ = loss_and_grad(scores, y[i:i + batch])
        losses.append(loss * len(scores))
        preds.append(scores.argmax(axis=1))
    preds = np.concatenate(preds)
    return float((preds == y).mean()), float(sum(losses) / len(y)), preds


def confusion_matrix(y, preds, k):
    m = np.zeros((k, k), np.int64)
    np.add.at(m, (y, preds), 1)                                        # rows true, columns predicted
    return m

"""gradient_check.py - proof that the hand-written backward pass is correct.

Idea: the gradient of a weight says how much the loss changes when that weight
changes a tiny bit. That can also be MEASURED: nudge the weight up by eps, then
down by eps, and see how the loss moves (the "central difference"). If my
backward pass is right, the two numbers agree to many digits.

Run:  python gradient_check.py
It uses float64 so that rounding does not hide a real mistake.
"""
import numpy as np
from cnn_numpy import Net, loss_and_grad

EPS = 1e-5            # size of the nudge
PER_LAYER = 20        # random weights tested in every weight array


def loss_of(net, x, y):
    loss, _ = loss_and_grad(net.forward(x), y)
    return loss


def relative_difference(net, x, y, weights, pos, analytic, eps):
    """Nudge one weight up and down by eps and compare the measured slope with mine."""
    old = weights[pos]
    weights[pos] = old + eps
    up = loss_of(net, x, y)
    weights[pos] = old - eps
    down = loss_of(net, x, y)
    weights[pos] = old                                   # put it back
    numeric = (up - down) / (2 * eps)                    # central difference
    return abs(numeric - analytic) / max(1e-12, abs(numeric) + abs(analytic))


def main(seed=0):
    rng = np.random.default_rng(seed)
    net = Net(seed=seed, dtype=np.float64)
    x = rng.random((4, 3, 64, 64))               # 4 random "pictures" in 0..1
    y = rng.integers(0, 12, size=4)              # 4 random "right answers"

    # Gradients from my backward pass.
    loss, d = loss_and_grad(net.forward(x), y)
    net.backward(d)
    print(f"loss on random data: {loss:.4f}")

    worst, retried = 0.0, 0
    for name, layer in net.named:
        for p in ("W", "b"):
            weights = getattr(layer, p)
            analytic = getattr(layer, "d" + p)
            layer_worst = 0.0
            for _ in range(PER_LAYER):
                pos = tuple(rng.integers(0, s) for s in weights.shape)   # one random weight
                rel = relative_difference(net, x, y, weights, pos, analytic[pos], EPS)
                if rel > 1e-5:
                    # ReLU and max pooling have "kinks". If the nudge pushes one unit
                    # across its kink, the measured slope is slightly off even though
                    # my gradient is right. A 10 times smaller nudge avoids the kink.
                    # A real bug stays wrong for every nudge size.
                    retried += 1
                    rel = relative_difference(net, x, y, weights, pos, analytic[pos], EPS / 10)
                layer_worst = max(layer_worst, rel)
            print(f"  {name + '_' + p:9s} shape {str(weights.shape):16s} worst relative difference {layer_worst:.1e}")
            worst = max(worst, layer_worst)

    print(f"weights re-measured with a smaller nudge (kinks): {retried} of {PER_LAYER * 10}")
    print(f"biggest relative difference: {worst:.1e}")
    print("PASS" if worst < 1e-5 else "FAIL: the backward pass has a mistake")
    return worst

    main()

"""hx711.py - read the HX711 load cell amplifier through two Raspberry Pi GPIO pins.

Wiring (physical pin numbers on the 40-pin header):
  HX711 VCC -> pin 1 (3.3 V)     HX711 GND -> pin 6
  HX711 DT  -> pin 29 (GPIO 5)   HX711 SCK -> pin 31 (GPIO 6)

How one reading works:
  1. The HX711 pulls DT low when a new reading is ready (10 times a second).
  2. The Pi gives 24 short pulses on SCK. After each pulse the HX711 puts the
     next bit on DT, biggest bit first.
  3. A 25th pulse tells the HX711 "next time, channel A with gain 128 again".
  4. The 24 bits are a signed number in two's complement.
The trap: if SCK stays high for more than 60 microseconds, the HX711 powers
down and the reading is lost. Linux can pause this program at any moment, so
now and then a reading comes out wrong. weight_filter.py removes those.

On a laptop RPi.GPIO does not exist. A small stand-in keeps this file
importable, and SimulatedHX711 gives believable readings for demos.
"""
import random
import time

try:
    import RPi.GPIO as GPIO          # on the Pi this comes from the rpi-lgpio package
    ON_PI = True
except ImportError:                  # laptop: a do-nothing stand-in with the same names
    ON_PI = False

    class _FakeGPIO:
        BCM, IN, OUT, LOW, HIGH = "BCM", "IN", "OUT", 0, 1

        def setmode(self, mode): pass
        def setwarnings(self, flag): pass
        def setup(self, pin, direction, initial=0): pass
        def output(self, pin, value): pass
        def input(self, pin): return 0
        def cleanup(self, pins=None): pass

    GPIO = _FakeGPIO()

DT_PIN = 5       # GPIO 5 = physical pin 29, data from the HX711
SCK_PIN = 6      # GPIO 6 = physical pin 31, clock pulses from the Pi


class HX711:
    """The real chip, read bit by bit."""

    def __init__(self, dt_pin=DT_PIN, sck_pin=SCK_PIN):
        self.dt, self.sck = dt_pin, sck_pin
        GPIO.setwarnings(False)
        GPIO.setmode(GPIO.BCM)                         # use GPIO numbers, not pin numbers
        GPIO.setup(self.sck, GPIO.OUT, initial=GPIO.LOW)
        GPIO.setup(self.dt, GPIO.IN)

    def is_ready(self):
        return GPIO.input(self.dt) == 0                # DT low means "a reading is waiting"

    def read_raw(self, timeout=1.0):
        """One 24-bit reading as a signed whole number, or None after `timeout` seconds."""
        deadline = time.monotonic() + timeout
        while not self.is_ready():
            if time.monotonic() > deadline:
                return None                            # wire loose, chip unpowered, or swapped pins
            time.sleep(0.001)
        value = 0
        for _ in range(24):                            # 24 bits, biggest bit first
            GPIO.output(self.sck, 1)                   # pulse up: the HX711 puts the next bit on DT
            GPIO.output(self.sck, 0)                   # pulse down at once: keep SCK high only briefly
            value = (value << 1) | GPIO.input(self.dt)
        GPIO.output(self.sck, 1)                       # 25th pulse: channel A, gain 128 next time
        GPIO.output(self.sck, 0)
        if value & 0x800000:                           # top bit set: a negative number
            value -= 1 << 24                           # two's complement for 24 bits
        return value

    def close(self):
        GPIO.cleanup([self.dt, self.sck])


class SimulatedHX711:
    """A pretend scale for laptop demos and tests.

    It behaves like my real one: offset 123,450 counts, 431 counts per gram,
    a little noise, and now and then a wild reading like the Linux timing trap.
    """

    def __init__(self, offset=123_450, counts_per_gram=431.0, noise_g=0.4, wild_every=1200, seed=1):
        self.offset, self.cpg = offset, counts_per_gram
        self.noise_g, self.wild_every = noise_g, wild_every
        self.grams = 0.0
        self.rng = random.Random(seed)

    def is_ready(self):
        return True                                    # a pretend reading is always waiting

    def set_load(self, grams):
        """Pretend an item of this weight is now on the tray (0 = empty)."""
        self.grams = float(grams)

    def read_raw(self, timeout=1.0):
        time.sleep(0)                                  # the real chip makes us wait; the demo does not
        if self.wild_every and self.rng.randrange(self.wild_every) == 0:
            return self.rng.choice([-1, 1]) * self.rng.randrange(1_000_000, 8_000_000)
        g = self.grams + self.rng.gauss(0, self.noise_g)
        return int(round(self.offset + g * self.cpg))

    def close(self):
        pass

From raw counts to a steady weight in grams. 105 lines.

"""weight_filter.py - turn noisy raw HX711 numbers into one steady weight in grams.

Three steps for every new raw reading:
  1. Clean:  take the median of the newest 5 raw readings. One wild reading
             (the Linux timing trap) can never be the middle of 5, so it vanishes.
  2. Convert: grams = (raw - offset) / counts_per_gram.
  3. Steady: the weight is "steady" when the newest 8 cleaned values differ by
             less than 2 g. The steady weight is their average.
It also re-tares by itself: if the tray has been empty and steady for 5 s
(50 readings), the current reading becomes the new zero. That removes slow drift.

Small example (offset 0, 1 count per gram, so raw numbers are grams):
>>> f = WeightFilter(offset=0, counts_per_gram=1.0)
>>> for raw in [412, 413, 2600, 412, 411, 412, 413, 412, 412, 411, 412]:
...     g = f.add(raw)
>>> round(g), f.steady, round(f.weight, 1)
(412, True, 412.1)
>>> f.add(None) == g          # a timed-out reading changes nothing
True
"""
from collections import deque
from statistics import median

MEDIAN_N = 5            # readings in the median window
STEADY_N = 8            # cleaned readings that must agree
STEADY_BAND_G = 2.0     # ... within this many grams
ITEM_ON_G = 20.0        # above this, something is on the tray
ITEM_OFF_G = 10.0       # below this, the tray counts as empty
RETARE_AFTER = 50       # empty and steady for 50 readings (5 s) -> new zero


class WeightFilter:
    def __init__(self, offset, counts_per_gram, median_n=MEDIAN_N, steady_n=STEADY_N,
                 band_g=STEADY_BAND_G):
        self.offset = float(offset)
        self.cpg = float(counts_per_gram)
        self.band = band_g
        self.raw = deque(maxlen=median_n)       # newest raw readings
        self.clean = deque(maxlen=steady_n)     # newest cleaned values, in grams
        self.empty_count = 0                    # readings in a row with an empty, steady tray

    def to_grams(self, raw):
        return (raw - self.offset) / self.cpg

    def add(self, raw):
        """Feed one raw reading (or None). Returns the newest cleaned weight in grams."""
        if raw is None:                         # read_raw timed out: keep what we have
            return self.clean[-1] if self.clean else 0.0
        self.raw.append(raw)
        g = self.to_grams(median(self.raw))
        self.clean.append(g)
        self._auto_retare()
        return g

    @property
    def steady(self):
        return len(self.clean) == self.clean.maxlen and max(self.clean) - min(self.clean) < self.band

    @property
    def weight(self):
        """The average of the newest cleaned values: the number I bill."""
        return sum(self.clean) / len(self.clean) if self.clean else 0.0

    def tare(self, raw_readings):
        """Make the average of these raw readings the new zero (start-up uses 20 readings)."""
        good = sorted(r for r in raw_readings if r is not None)
        if good:
            self.offset = float(median(good))
        self.raw.clear()
        self.clean.clear()

    def _auto_retare(self):
        if self.steady and abs(self.weight) < ITEM_OFF_G:
            self.empty_count += 1
            if self.empty_count >= RETARE_AFTER:
                self.offset = float(median(self.raw))   # the tray is empty: this is zero now
                self.clean.clear()
                self.empty_count = 0
        else:
            self.empty_count = 0

def median_of_readings(scale, n=READINGS):
    """The median of n good readings; timed-out readings (None) are skipped."""
    values = [r for r in (scale.read_raw() for _ in range(n)) if r is not None]

# The tray in HSV colour space: hue 90..130 is blue (OpenCV hue runs 0..179).

class Camera:

"""bill.py - prices and the itemised bill, with money kept in whole paise.

Why paise: computers store decimal rupees like 8.78 only approximately, so
adding many of them can give 15.079999999999998 instead of 15.08. Whole
numbers of paise are exact, so every sum is exact. Rupees appear only when
the bill is printed.

>>> price_paise(412, 35)          # 412 g of tomato at Rs 35/kg
1442
>>> rupees(1442)
'Rs 14.42'
>>> price_paise(1033, 25)         # 2,582.5 paise rounds half up to 2,583
2583
>>> b = Bill()
>>> _ = b.add("Tomato", 412, 35)
>>> _ = b.add("Onion", 1032.6, 25)
>>> b.total_paise, rupees(b.total_paise)
(4025, 'Rs 40.25')
"""
import csv
from pathlib import Path


def load_prices(path):
    """Read prices.csv into a dictionary {"Tomato": 35, ...} of whole rupees per kg."""
    prices = {}
    with open(path, newline="", encoding="utf-8") as f:
        for row in csv.DictReader(f):
            prices[row["item"].strip()] = int(row["rupees_per_kg"])
    return prices


def check_prices(prices, class_names):
    """Stop at start-up if any class the network knows has no price."""
    missing = [name for name in class_names if name not in prices]
    if missing:
        raise ValueError(f"prices.csv has no price for: {', '.join(missing)}")


def price_paise(grams, rupees_per_kg):
    """Price of `grams` (rounded to whole grams) at `rupees_per_kg`, in whole paise.

    paise = grams x rupees_per_kg x 100 / 1000, rounded half up. All whole numbers.
    """
    g = int(round(grams))                     # the bill shows and charges whole grams
    return (g * rupees_per_kg * 100 + 500) // 1000


def money(paise):
    """1442 -> '14.42', using whole-number maths only."""
    return f"{paise // 100}.{paise % 100:02d}"


def rupees(paise):
    """1442 -> 'Rs 14.42'. Paise become rupees only when they are shown."""
    return "Rs " + money(paise)


class Bill:
    """The customer's bill: a list of lines and a total, all in paise."""

    def __init__(self):
        self.lines = []                       # each line: (name, grams, rupees_per_kg, paise)

    def add(self, name, grams, rupees_per_kg):
        line = (name, int(round(grams)), rupees_per_kg, price_paise(grams, rupees_per_kg))
        self.lines.append(line)
        return line

    def remove_last(self):
        if self.lines:
            self.lines.pop()

    def clear(self):
        self.lines = []

    @property
    def total_paise(self):
        return sum(line[3] for line in self.lines)

    def text(self):
        """The bill as lines of text, the same layout the screen shows."""
        rows = [f"{'Item':<14}{'Grams':>7}{'Rs/kg':>7}{'Rs':>9}"]
        for name, g, rpk, p in self.lines:
            rows.append(f"{name:<14}{g:>7}{rpk:>7}{money(p):>9}")
        rows.append("-" * 37)
        rows.append(f"{'Total':<28}{money(self.total_paise):>9}")
        return "\n".join(rows)

            for k, name in enumerate(CLASSES):
                tk.Button(grid, text=name, font=SMALL, width=13, height=2, bg="white", fg=TEXT,
                          command=lambda n=name: self.add(n)).grid(row=k // 4, column=k % 4, padx=4, pady=4)
        else:
            buttons = [(CLASSES[i], lambda n=CLASSES[i]: self.add(n), TEAL) for i, _ in guesses[:3]]
            buttons.append(("Other items", lambda: self.choose_screen(full_list=True), GREY))
            self.screen(title, f"{self.item['grams']:.0f} g on the tray", buttons, big_font=MID)

    # ------------------------------------------------------------------ the tick
    def tick(self):
        """Runs every 100 ms: one scale reading, one filter update, one state step."""
        try:
            raw = self.scale.read_raw(timeout=0) if self.scale.is_ready() else None
            self.no_reading = 0 if raw is not None else self.no_reading + 1
            grams = self.filter.add(raw)
            self.status.config(text="Scale not responding" if self.no_reading > NO_READING_LIMIT else "")
            self.step(grams)
        except Exception:
            traceback.print_exc()                    # keep the kiosk alive; the log shows what happened
        finally:
            self.root.after(TICK_MS, self.tick)

    def step(self, grams):
        s, f = self.state, self.filter
        if s == WAITING:
            if grams > self.on_g:
                self.go(SETTLING)
        elif s == SETTLING:
            self.big.config(text=f"{grams:.0f} g")   # live weight
            if grams < self.off_g:
                self.go(WAITING)                     # it was lifted off again
            elif f.steady:
                self.identify()
        elif s in (SHOWING, CHOOSING):
            if grams < self.off_g:
                self.go(WAITING)                     # taken off without adding: nothing is billed
            elif f.steady and abs(f.weight - self.item["grams"]) > CHANGED_G:
                self.go(SETTLING)                    # something was added or swapped: weigh again
        elif s == REMOVE:
            if grams < self.off_g:
                self.go(WAITING)
        # BILL: the scale is ignored while the customer reads the bill

    def identify(self):
        """One photo, one prediction. Called once per item, when the weight is steady."""
        self.state = IDENTIFYING
        guesses = None
        photo = self.camera.take_photo()
        box = camera.find_item_box(photo) if photo is not None else None
        if box is not None:
            x = prepare_image(crop_with_margin(photo, box))
            guesses = top_k(self.net, x, 3)
        else:
            self.status.config(text="Could not see the item, please choose")
        self.item = {"grams": self.filter.weight, "guesses": guesses}
        if guesses and guesses[0][1] >= self.threshold:
            self.go(SHOWING)
        else:
            self.go(CHOOSING)

    # ------------------------------------------------------------------ buttons
    def add(self, name):
        self.bill.add(name, self.item["grams"], self.prices[name])
        self.go(REMOVE)

    def new_customer(self):
        self.bill.clear()
        self.go(WAITING)

    def demo_key(self, event):
        key = event.char.lower()
        if key == " ":
            self.scale.set_load(0)
        elif key in DEMO_ITEMS:
            name, grams, colour = DEMO_ITEMS[key]
            self.camera.colour = colour
            self.scale.set_load(grams)

    def quit(self):
        self.scale.close()
        self.camera.close()
        self.root.destroy()


def main():
    parser = argparse.ArgumentParser(description="Self-checkout kiosk app")
    parser.add_argument("--simulate", action="store_true", help="simulated scale and fake camera (laptop demo)")
    parser.add_argument("--windowed", action="store_true", help="an 800 x 480 window instead of fullscreen")
    args = parser.parse_args()
    root = tk.Tk()
    KioskApp(root, simulate=args.simulate, windowed=args.windowed)
    root.mainloop()


if __name__ == "__main__":
    main()
